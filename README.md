# Job Description Analyser

AI-powered tool that analyses job descriptions using Google Gemini API 
and returns required skills, experience level, and a match score.

## Tech Used
- Python
- Google Gemini API (Free)
- Prompt Engineering
- Pandas
- GitHub

## How to Run
1. Clone the repo
   git clone https://github.com/nagakumarswamy/job-description-analyser.git

2. Install dependencies
   pip install google-generativeai pandas

3. Get your free Gemini API key from:
   https://aistudio.google.com/app/apikey

4. Add your API key in analyser.py (line 5)
   API_KEY = "your-gemini-api-key-here"

5. Run the script
   python analyser.py

## Sample Output
- Required Skills: Python, SQL, Data Analysis, Power BI
- Experience Level: Fresher
- Match Score: 85/100
- Recommendation: Strong match, consider learning Tableau
