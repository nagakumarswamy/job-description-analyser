# Job Description Analyser

AI-powered tool that analyses job descriptions using Claude API 
and returns required skills, experience level, and a match score.

## Tech Used
- Python
- Claude API (Anthropic)
- Pandas
- Prompt Engineering

## How to Run
1. Clone the repo
   git clone https://github.com/nagakumarswamy/job-description-analyser.git
2. Install dependencies
   pip install anthropic pandas
3. Add your Claude API key in analyser.py
4. Run the script
   python analyser.py

## Sample Output
- Required Skills: Python, SQL, Data Analysis
- Experience Level: Junior
- Match Score: 85/100
